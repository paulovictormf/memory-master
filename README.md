# Memory Master

Jogo da memória moderno desenvolvido com HTML, CSS e JavaScript puro.

## Recursos

- Três níveis de dificuldade
- Cronômetro
- Contador de jogadas
- Combo de acertos
- Cálculo de precisão
- Recorde salvo no navegador
- Sons gerados pelo próprio navegador
- Tema claro e escuro
- Animações 3D
- Efeito de partículas
- Layout responsivo

## Como executar

Abra o arquivo `index.html` em qualquer navegador moderno.

Não é necessário instalar nada.
